# Slice A — Gross fair-value distributions for Munich repair invoices

**2026-11-21 · START Munich / QuantCo Claim to Fame**

**Cache actual Munich rates** and use the existing cheap model call to identify the work, parts, and billing scope. Compute the gross amount in code. A 0.2 m² wall repair can involve a minimum labor block, fittings, and a second visit. A large-project €/m² rate misses those costs. I found no released model or dataset that supplies calibrated p10/p50/p90 values for the maximum a Munich claims expert would accept.

**Target.** For an eligible line, estimate the maximum reasonable **gross line total**, including 19% VAT. The line total is quantity × gross unit price. Treat coverage and relatedness as a separate probability of positive fair value. A local posted price anchors the market price of the service. The expert's maximum, the amount of work the expert justifies, and the applicability of the offer are additional unknowns. ## Rank by expected competition benefit

| Rank | Candidate | Expected advantage and operational cost |
| --- | --- | --- |
| **1** | Munich tariffs + explicit job scope + deterministic labor/material calculation | High. Zero live external lookups or extra model calls. Direct local anchors correct location, unit, scope, and small-job errors together. |
| **2** | Source-weighted blend with the current one-call estimator, checked on withheld providers | High. Keeps model judgment for ambiguous work and widens disagreement. A modest set of fresh, comparable quotes can expose bias quickly. The blend is cheap arithmetic. |
| **3** | Public product prices and manufacturer service tariffs and optional construction labor norms | Medium. Fills specific part and labor gaps when the exact item matches. Store references offline. Trade names alone are insufficient. |
| **4** | Split conformal adjustment on held-out matched prices and a selected second model as a disagreement check | Medium to low today. Both need a proxy test. Conformal runtime is negligible. Each model call adds fees and timeout exposure. Reserve a second opinion for offline evaluation or a demonstrated expensive failure mode. |
| **5** | Train a text/vision quantile model, use TabPFN as primary, or mine tender notices live | Low today. Domain labels and access are the bottleneck. Useful as an offline experiment once comparable rows exist. |

## 4. Build a cached price prior in three hours

### A. Curate observations before modeling

1. **0–45 min.** Record the tariffs above, then add independent offers for the frequent job families. Start with 20–40 priority category/unit/scope rows. Cover routine and emergency visits, diagnostics, basic part replacement, wall opening and finishing, drying, tiles, paint, flooring, roof patches, glazing, windshield and appliance service. Record materials as separate observations even when using them to build an installed price.
2. **45–100 min.** Normalize observations into a small CSV or SQLite database. Keep rows for material-only, labor-only, installed-per-unit, and inclusive visit packages. Normalize `Std.` → h, `Stk.` → pcs, `lfm` → m, and preserve the denominator for 100-unit records. Add canonical repair aliases in German and English. Separate same-company offers and marketplace mirrors from independent providers. Restrict primary numeric observations to known VAT and scope. Keep uncertain ranges as reviewer references.
3. **100–150 min.** Make priors by exact trade/category/unit/scope/quantity band. Where there are enough independent comparable offers, calculate provider-weighted log-price quantiles. Else use the median of exact observations and an explicit width floor. Lower-censored “from” quotes stay one-sided. One package anchor can locate a component without resolving its right tail. For small repairs construct a total using a minimum labor block, materials, equipment and applicable shared charges once. Encode scenario and source IDs.
4. **150–180 min.** Run the holdout, unit and timing checks below. Freeze the cache version and the rule for weighting sparse sources. In round play, use local lookups and the cheap existing structured request for all lines. Set a first valid submission target near **15 s** during dry runs and budget the current cutoff around **54 s** for optional improvements. These are proposed budgets. Measure elapsed time through PDF parsing, model and response construction before expecting either target.

Suggested observation schema

`trade, category, aliases, unit, scope, qty_min, qty_max, quote_kind, price_original, vat_basis, quote_date, region, provider_key, included, excluded, source_url, source_terms`

Derived lookup row

`trade, category, unit, scope, qty_band, eur_gross_p10, eur_gross_p50, eur_gross_p90, independent_provider_count, provenance_ids, uncertainty_basis`

With so few providers this is a width choice to challenge offline. At `z=.1/.9`, the multipliers on the median are about **0.726/1.378**. ### B. Use the cheap model for scope and shrink prices on the correct basis

- **Map before pricing.** Ask the model for category, work operation, validated unit, bundled components, emergency status, plausible labor/time or part specification, and existing validity and quantity estimates. Limit it to a few well-matched local category IDs. Use `hourly`, `per item`, `per area`, and `job total` as different billing bases. Compare the actual requested unit and invoice quantity with the cached row. If quantities are disputed, use `q_eff = min(q_invoiced, q_justified)` as the current modeling choice and show sensitivity for expensive lines.
- **Calculate the job basis.** For hours with a directly matched tariff, multiply the justified hours by gross EUR/h. For task bundles, simulate or evaluate joint labor and materials scenarios. Apply justified minimum time and any travel/mobilization charge to the applicable line once. Convert an implied per-m² rate from that line's modeled total if the schema requires it. For Game 0, two hours of detection/opening may fit an hourly scenario. A separately quoted instrumented report package is a different scenario. The copper repair needs the 15 mm pipe and fittings plus justified labor. A 0.2 m² closure/replaster/retile line also needs minimum patch labor and any justified return visit. Coverage can still set boiler service to zero independently of its plausible local market price.
- **Blend only comparable distributions.** Let `F_cache` and `F_llm` describe the same positive **gross total** and same target. If estimating market price first, ask the LLM for market-price quantiles and apply the expert-threshold adjustment downstream. If retaining the current LLM threshold prompt, convert the cache market prior to a threshold prior first. Use the arithmetic mixture `F(x)=w·F_cache(x)+(1−w)·F_llm(x)`. Solve for its quantiles by bisection on log price. For either component, model log price as a normal on each side of the median with `s_low=log(p50/p10)/1.28155` and `s_high=log(p90/p50)/1.28155`, and a width floor. This preserves all three quantiles when the floor is inactive. An example starting cache weight is **0.65** on an exact, independently corroborated local scope and **0.25** on a partial match. Freeze these heuristic weights and test sensitivity. If the LLM already received the same numeric quotes, use the cache to construct the price and model output for scope. A shared anchor is one piece of evidence.
- **Optional small calibrator.** If comparable labels exist, fit a log residual for cache and LLM point estimates using a pooled intercept and strongly shrunk group offsets. Estimate weights by blocked holdout. A precision-weighted Gaussian update is justified only with estimated source errors and a defensible correlation model. An arithmetic mixture avoids claiming independence and retains the tails implied by conflicting sources. For unknown ADAS, glass class or visits, keep materially distinct scenarios and mix their distributions.
- **Keep the price-to-threshold shift explicit.** Let `R` be the market price and model `log(T_positive)=log(R)+δ` after quantity/scope correction. Test median thresholds at **1.00×, 1.15× and 1.30×** local prices. These are scenario assumptions. No uniform surcharge is learned here. Run a downside stress at **0.85×** because a local quoted price may already sit above the expert's threshold. If the strategic conclusion flips across this range, surface that dependence and preserve a wider belief. For example, two independent blinded reviewer estimates on a case can inform the shift more directly than more model samples.
- **Integrate once at the existing boundary.** `claimbot/schema.py` expects **net per-unit** quantiles, and `pricing.py` already multiplies by its effective quantity and VAT. If feeding it a gross line total, divide by `q_eff×1.19` exactly once and let the current code restore the total. Alternatively let the pricing function consume the full gross distribution directly. The current symmetric lognormal retains median and log width and can lose tail asymmetry. Test whether retaining the mixture materially changes relevant quantiles before extending the rule. With eligibility probability `r`, use `P(T=0)=1−r` and `F_T(x)=1−r+r·F_positive(x)` for `x≥0`. ### C. Check without hidden ground truth

| Check | What to report |
| --- | --- |
| **Blind price holdout** | Aim for **30–60 comparable positive proxy items** across providers if available. Use real quotes, public awarded lines where scope is explicit, and published tariffs with true units. Hide prices and identifying hints from the prompt. Group by provider and contract, avoid mirrors, and reserve an untouched test split. Compare current prompt, cache-only, and blend. Report median absolute log error, signed bias, p10/p50/p90 pinball loss, 80% coverage, both tail miss rates, interval score, and by-scope counts. Include uncertainty bars or raw counts for small samples. This measures prices we can observe. |
| **Conformal proxy adjustment** | Fix the estimator before using calibration data. On eligible positive log prices, compute `s_i=max(log L_i−log y_i, log y_i−log U_i)` from a dedicated calibration split. Set `k=ceil((n+1)·0.8)`, use the kth ordered score, and return `[L·exp(−s_k), U·exp(s_k)]` with safe endpoint ordering. A pure-widening policy may use `max(0,s_k)`. If the index exceeds the calibration size, there is no finite rank-based bound at that level. Example **n=40 → k=33**. Validate on untouched providers. Estimate median bias and tail calibration separately, allowing for sample size. Exchangeability and the proxy price definition bound the coverage claim. |
| **Metamorphic price checks** | Check the 19% gross/net round trip and 100 m² to 1 m² conversion. Decimal commas and unit aliases preserve the result. Doubling quantity doubles the variable cost. Apply each minimum charge, removal, reinstall and parts cost once. Material-only costs less than the corresponding installed scenario. Unknown ADAS keeps both variants. Explicit exclusion preserves mass at zero. Reordering rows preserves their IDs and values. |
| **Threshold checks** | Use Game 0 only for parse, reconstruction, stable output and plausible scope. If feasible, have two humans independently set plausible expert maxima blind to the model for 10–20 representative test vignettes. Report inter-rater agreement and disagreement with the market proxy. Replay fixed strategies under the threshold scenarios and plausible opponent behaviors, including correlated price errors. Aggregate score deltas mix unknown bids, acceptance limits and cases, so they cannot identify `t`. |
| **Runtime and decision gate** | On sanitized fixtures, time cold and warm parses and model calls, and simulate slow/error paths without the game API. Log elapsed time, tokens, number of anchored lines, price difference by match class, and first/last available submission time.
